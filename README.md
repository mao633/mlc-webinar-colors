# MLC Webinar — Colors

Static landing page for the MLC webinar on 6 October 2026.

## Deployment

GitHub `main` is connected to Vercel for automatic production deployments. The custom domain is `webinar.mlcpresentations.com`.

## Required assets and registration

The supplied HTML references image files in `Assets/` and posts registrations to `/api/webinar-handler`. Add the source assets and configure the registration service before promoting the page for use.
